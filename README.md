## The word

> Al

Grandma does not know what "AI" is. She has decided it is a man named
Al. Al is very clever, Al does the typing now, and she would like Al to
call her back.

## How it works

`main.py` is a deterministic program that writes the single word above
to `/output/entry.txt` — exactly two bytes, no trailing newline, no
randomness, no network. Run it locally (the grader sandbox writes to
`/output`):

```sh
python3 main.py
```
